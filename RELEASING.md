# Формат каталога и выпусков

Публичные данные редактируются в форме выпуска Game Dubber и сохраняются здесь.
Каталог сайта собирается при деплое; исходные JSON сами по себе не включают скачивание.

- `.github/catalog.json`: `author`, `site_url`, `github_repository` (`владелец/репозиторий`),
  `links` (пары `label`/`url`) и условия использования `license_text`.
- `<игра>/game.json`: `slug` (постоянный адрес), `title`, `summary`, `information`,
  `description`, `steam_url`, `visible`, `cover`, `screenshots`, `installer_poster`.
  Изображения используют относительный `file`, подпись `caption` и `alt`.
- `<игра>/releases/<версия>.json`: `version` (`0.1.0`), `components` (`text`/`audio`),
  `builds` (ID готовых модов), `game_build_id`, языки подключения `text_locale`/`audio_locale`,
  `compatibility`, `changes`, `known_issues`, `instructions`, `prerelease`, `assets`,
  `mirrors` (пары `label`/`url`), `telegram_post_url`.
- `assets`: `kind` (`exe`, `zip`, `document`, `image`), `name`, `size` в байтах,
  `sha256` (64 строчных hex). Каждый файл должен быть меньше 2 GiB.

Пути относительные, без `..`, обратных слешей и ссылок за пределы репозитория.
EXE/ZIP и проверенные материалы подготовки находятся в игнорируемом
`<игра>/release/<версия>/`. Бинарники не коммитятся; история доступна в GitHub Releases.
Пустые зеркала, Telegram-пост и изображения не отображаются.

GitHub-тег выпуска: `<slug>-v<версия>`, например `galactic-racer-ru-v0.1.0`.
Статус определяется GitHub Release; черновик не доступен посетителю для скачивания.
Старшая опубликованная версия появляется на сайте. Общий GitHub latest не используется.
Версия берётся из выбранных готовых модов; подготовка не пересобирает их.

После проверки EXE и ZIP владелец явно публикует выпуск. Чужие staged-изменения,
расхождение веток, изменённый комплект и конфликт опубликованной версии блокируют
публикацию. Повтор продолжает черновик, а после успеха GitHub повторяет только
обновление сайта. Ссылки на ручные зеркала можно добавить позднее без пересборки.
Workflow сайта получает точный SHA этого репозитория и конкретный тег.
Данные авторизации сюда не сохраняются.
