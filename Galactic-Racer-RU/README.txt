УСТАНОВКА ИЗ ZIP
1. Закройте игру.
2. Откройте папку с игрой. В Steam: правой кнопкой по игре в библиотеке → Управление → Просмотреть локальные файлы.
3. Распакуйте содержимое архива в открытую папку с игрой и подтвердите замену файлов.
4. В настройках игры выберите язык текста — Английский (English). Возможно после выбора языка понадобится перезапустить игру!

УСТАНОВКА ЧЕРЕЗ EXE
1. Закройте игру.
2. Запустите установщик и следуйте подсказкам, пока перевод не будет установлен
3. В настройках игры выберите язык текста — Английский (English). Возможно после выбора языка понадобится перезапустить игру!

ОБНОВЛЕНИЕ
Закройте игру. Установите новую версию тем же способом:
ZIP — повторите распаковку из шага 3 и подтвердите замену файлов.
EXE — запустите новый установщик, он заменит файлы перевода.

УДАЛЕНИЕ
После установки из ZIP удалите папку мода «RUSIK_by_Byrnane» целиком:
Griffin/Content/Paks/~mods/RUSIK_by_Byrnane
После установки через EXE запустите .RUSIK/uninstall.exe в папке с игрой.
